# دليل الأصول — الأدب الأندلسي: خطبة طارق بن زياد

هذا الملف يشرح كل الصور والملفات الصوتية التي يستخدمها العرض (`index.html`)،
وأين تضعها، وكيف تغيّرها لاحقًا.

## هيكل المجلدات المطلوب

```
/
├── index.html
├── README-ASSETS.md
└── assets/
    ├── images/
    │   ├── hero.jpg
    │   ├── map.jpg
    │   ├── strait.jpg
    │   ├── battle.jpg
    │   ├── architecture.jpg
    │   ├── manuscript.jpg
    │   ├── portrait.jpg
    │   └── closing.jpg
    └── audio/
        └── background.mp3
```

العرض **يعمل حتى لو لم توجد أي صورة أو ملف صوتي بعد** — تظهر خلفية بديلة
(تدرّج لوني بالألوان الترابية للعرض) بدل أي صورة مفقودة، ولا يتوقف العرض
أو تظهر أخطاء.

---

## الصور المطلوبة (Required)

| الملف | أين تُستخدم | الوصف المقترح |
|---|---|---|
| `hero.jpg` | شريحة الغلاف | صورة أفقية قوية (ساحل/مضيق عند الغروب أو الفجر، أو أفق البحر) — هذه أهم صورة في العرض |
| `map.jpg` | شريحة "بلاد الأندلس" | خريطة تاريخية أو حديثة لشبه جزيرة الأندلس وموقعها من أوروبا وشمال إفريقيا |
| `strait.jpg` | شريحتا "بداية الفتح" و"عبور المضيق" | صورة للمضيق (مضيق جبل طارق) — ماء، سفن، أو الشاطئين معًا |
| `battle.jpg` | شريحة "المعركة الحاسمة" | مشهد يوحي بالمواجهة: سهل مفتوح، غبار، خيول، أو تصوير رمزي للمعركة (تجنّب صورًا دموية) |
| `architecture.jpg` | شريحتا "تأسيس الدولة" و"خصائص النص" | عمارة أندلسية (أقواس، أبواب، تفاصيل معمارية) |
| `manuscript.jpg` | خلفية شرائح نص الخطبة والمفردات | مخطوطة أو خط عربي أو نسيج ورقي قديم، بدرجات هادئة تسمح بوضوح النص فوقها |
| `portrait.jpg` | شريحة "طارق بن زياد" | تصوير رمزي (لا صورة فوتوغرافية حقيقية، لأنها غير موجودة تاريخيًا) — تمثال، سيف، أو مشهد رمزي للقيادة |
| `closing.jpg` | شريحة "الخلاصة" | صورة ختامية هادئة تجمع طابع العمارة أو المخطوطات لإنهاء العرض بإحساس دافئ |

**المقاس المقترح لكل الصور:** 1920×1080 بكسل أو أوسع (تُقصّ تلقائيًا لتملأ الشاشة).
**الصيغة:** JPG بجودة عالية، بحجم معقول (أقل من 500 كيلوبايت لكل صورة قدر الإمكان) لسرعة التحميل على الجهاز اللوحي.

## الصوت المطلوب (Required)

| الملف | الوصف |
|---|---|
| `background.mp3` | موسيقى خلفية **آلية فقط** (Instrumental) — بلا غناء ولا كلام. تُعاد تلقائيًا (Loop) بمستوى صوت هادئ (35%). تبدأ فقط بعد ضغط المستخدم على "ابدأ العرض" (لأن المتصفح يمنع التشغيل التلقائي قبل أي تفاعل). |

## كيف تضيف الصور والصوت

1. ارفع الملفات إلى GitHub داخل المسارات نفسها الموضحة في الهيكل أعلاه
   (`assets/images/...` و`assets/audio/...`).
2. تأكد من أن **أسماء الملفات** مطابقة تمامًا للأسماء في الجدول (حساسة لحالة الأحرف).
3. لا حاجة لتعديل أي كود — العرض يقرأ الأسماء تلقائيًا من نظام مركزي داخل `index.html`.

## كيف تغيّر اسم صورة أو مسارها

افتح `index.html` وابحث عن هذا الجزء في بداية كود الجافاسكربت:

```js
const ASSETS = {
  hero:         "assets/images/hero.jpg",
  map:          "assets/images/map.jpg",
  strait:       "assets/images/strait.jpg",
  battle:       "assets/images/battle.jpg",
  architecture: "assets/images/architecture.jpg",
  manuscript:   "assets/images/manuscript.jpg",
  portrait:     "assets/images/portrait.jpg",
  closing:      "assets/images/closing.jpg"
};
```

غيّر أي مسار هنا فقط، وسيتغيّر في كل الشرائح التي تستخدمه تلقائيًا.

## تغيير الموسيقى

ابحث عن:

```js
const AUDIO_CONFIG = {
  src: "assets/audio/background.mp3",
  volume: 0.35,
  loop: true
};
```

غيّر `src` لاسم ملف آخر، أو `volume` (من 0 إلى 1) حسب الحاجة.

## النشر على GitHub Pages

1. أنشئ مستودعًا (Repository) على GitHub وارفع إليه:
   - `index.html`
   - `README-ASSETS.md`
   - مجلد `assets/` بكل محتوياته
2. من إعدادات المستودع (Settings) → Pages، اختر الفرع (عادة `main`) والمجلد الجذري (`/root`).
3. بعد دقيقة أو دقيقتين، يصبح العرض متاحًا على رابط من نوع:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
4. افتح هذا الرابط من متصفح Chrome على الجهاز اللوحي، فعّل ملء الشاشة، وابدأ العرض.

## التحكم أثناء العرض

| المفتاح / الإجراء | الوظيفة |
|---|---|
| ← (السهم الأيسر) | الشريحة التالية |
| → (السهم الأيمن) | الشريحة السابقة |
| مسافة / Enter | الشريحة التالية |
| Esc | إغلاق نافذة التعريف أو الخروج من ملء الشاشة |
| F | تبديل ملء الشاشة |
| M | تشغيل/إيقاف الموسيقى |
| سحب من اليمين لليسار (Swipe) | الشريحة التالية |
| سحب من اليسار لليمين (Swipe) | الشريحة السابقة |
| الضغط على أي كلمة مضيئة | فتح تعريفها في نافذة منبثقة |

## وضع التطوير (Debug Mode)

داخل `index.html`، ابحث عن أول سطر في الجافاسكربت:

```js
const DEBUG = false;
```

غيّرها إلى `true` مؤقتًا أثناء التطوير لرؤية اسم الشريحة الحالية، حالة الموسيقى،
حالة النافذة المنبثقة، وأي صورة مفقودة — في مربع صغير أعلى يمين الشاشة.
أعدها إلى `false` قبل الاستخدام الفعلي في الفصل.
